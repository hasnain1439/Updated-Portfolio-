## 🌟 Overview

Welcome to my personal developer portfolio! This application highlights my experience and technical proficiencies as a **Full Stack Developer** specializing in **React.js, Next.js, React Native, Node.js, Express.js, PostgreSQL, MongoDB, Tailwind CSS, and Bootstrap**.

Designed with sleek glassmorphism, responsive micro-interactions, seamless dark/light theme switching, and fluid Framer Motion animations.

---

## ✨ Key Features

- 🌓 **Dark / Light Theme Toggle** with persistent context state and fluid transitions.
- ⚡ **Dynamic Hero Section** with interactive floating technology chips and direct resume download.
- 🎯 **Interactive Skills Matrix** filterable across *Frontend & Mobile*, *Backend & Database*, and *Tools & Workflow*.
- 💼 **Enhanced Career Timeline:**
  - Active status beacons with live pulsing indicators.
  - Interactive filter tabs (*All Experience*, *Full-Time*, *Part-Time*, *Internships*).
  - Expandable view (*Default 3 items + View All Toggle Button*).
- 📂 **Featured Projects Showcase** with live demo previews, GitHub source repositories, and category filters (*Full Stack & MERN*, *React Apps*, *Frontend & UI*).
- 📬 **Direct Contact & EmailJS Integration** with client-side validation and interactive feedback toasts.
- 📱 **Fully Responsive** across all screen sizes (mobile, tablet, laptop, and 4K displays).

## 🚀 Getting Started

Follow these steps to set up and run the project locally:

### 1. Clone the Repository
```bash
git clone https://github.com/hasnain1439/Updated-Portfolio-.git
cd Updated-Portfolio-
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Setup Environment Variables
Create a `.env` file in the root directory:
```env
VITE_EMAILJS_SERVICE_ID=your_service_id
VITE_EMAILJS_TEMPLATE_ID=your_template_id
VITE_EMAILJS_PUBLIC_KEY=your_public_key
```

### 4. Run Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 5. Build for Production
```bash
npm run build
```
